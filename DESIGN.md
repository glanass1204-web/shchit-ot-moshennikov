# DESIGN.md — Щит от мошенников

Записан по существующему `style.css` (стиль уже есть, новые страницы его повторяют, а не меняют).
Чувство: спокойно и надёжно, как банковское приложение, без паники. Аудитория: люди 55+ и их дети.

## Цвет (светлая / тёмная тема)
| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--bg` | #f3f5fb | #0a1230 | фон страницы |
| `--surface` | #ffffff | #131f45 | карточки, поле ввода |
| `--text` | #0f1b3d | #eef2ff | основной текст |
| `--muted` | #5b6685 | #9aa6c8 | подписи, второстепенный текст |
| `--border` | #dde3f1 | #25366a | границы |
| `--primary` | #3b6cff | #5b86ff | кнопки, ссылки, фокус |
| `--low` / `--medium` / `--high` / `--critical` | #16a34a / #eab308 / #f97316 / #e11d48 | светлее на тон | только уровни риска, не для декора |

Тёмная тема обязательна (есть переключатель). Один акцент — синий; цвета риска используются только для риска.

## Типографика
- Manrope (400, 600, 700, 800), запас: system-ui.
- Текст от 17px, строки до 65 символов. Заголовки 800, плотные.

## Форма
- Радиус 20px у крупных карточек, меньше у вложенных элементов. Одна мягкая тень `--shadow`.

## Компоненты
- Главная кнопка: заливка `--primary`, белый текст, высота от 48px, видимый фокус `--focus`.
- Шкала риска (полукруг 0–100) — фирменный элемент, использовать на лендинге как главный визуал.
- Иконки: эмодзи только внутри признаков риска (как в приложении), не в навигации.
