# Щит от мошенников

Веб-приложение (FastAPI + HTML/CSS/JS), которое проверяет подозрительные сообщения и ссылки на признаки мошенничества и показывает уровень риска от 0 до 100.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Откройте http://127.0.0.1:8000. Чтобы открыть с телефона в той же Wi-Fi сети — http://<IP-компьютера>:8000.

## Что проверяется

| Признак | Примеры |
|---|---|
| Просьба срочно перевести деньги | «срочно переведи», «скинь 5000 на карту», «займи» |
| «Безопасный счёт» | «переведите на безопасный/резервный счёт» |
| Запрос кода из SMS и данных карты | «продиктуйте код», CVV, PIN, «три цифры» |
| Подозрительная ссылка | поддельные домены банков и магазинов, сокращатели, IP-адреса, смешение латиницы и кириллицы, зоны .xyz/.top, http |
| Обещание выигрыша | «вы выиграли», приз, компенсация, «оплатите доставку/комиссию» |
| Давление и угрозы | блокировка, уголовное дело, ФСБ/полиция/ЦБ, «никому не говорите» |
| Дополнительно | «мама, это я, новый номер», установка AnyDesk/APK, «доход без риска», личные данные, переход в мессенджер, «уважаемый клиент» |

Каждый признак даёт вклад в риск; вклады объединяются по формуле `1 − Π(1 − pᵢ)` с бонусом за опасные сочетания. Уровни: 0–19 низкий, 20–49 средний, 50–74 высокий, 75–100 критический.

## API

`POST /api/analyze` — тело `{"text": "..."}`, ответ: `score`, `level`, `label`, `verdict`, `signs[]`, `links[]`, `recommendations[]`, `highlights[]`.
Документация Swagger: http://127.0.0.1:8000/docs

## Структура

```
main.py          — FastAPI: маршруты и раздача статики
analyzer.py      — правила, разбор ссылок, расчёт риска и рекомендаций
index.html, style.css, app.js — мобильный интерфейс, светлая/тёмная тема
ai_analyzer.py   — необязательный ИИ-разбор через OpenAI
tests/           — тесты анализатора и API
```

Текст сообщений не сохраняется и не логируется. Проверка по правилам не использует внешние сервисы. При согласии пользователя ИИ-анализ передаёт текст OpenAI. Проверка эвристическая и не даёт 100% гарантии.

## Подключение ИИ на Render

1. Обновите файлы репозитория и дождитесь развёртывания на Render.
2. Render → ваш сервис → Environment → Add Environment Variable.
3. Добавьте `OPENAI_API_KEY` (секретный ключ API), `AI_ENABLED=true`,
   `OPENAI_MODEL=gpt-4.1-mini`, `AI_DAILY_LIMIT=100`.
4. Сохраните настройки и дождитесь перезапуска. Ключ не размещайте в GitHub или браузерном коде.
5. На сайте отметьте «Дополнить проверку разбором ИИ» и проверьте тестовое сообщение.

ИИ показывает отдельный качественный риск и пояснения; баллы существующих правил сохраняются.
Без согласия пользователя внешний запрос не выполняется. Без ключа, при ошибке,
отказе модели, превышении лимита или таймауте остаётся обычная проверка.
Текст и ключ не записываются приложением в журнал. `store=false` отключает сохранение
Responses для последующего получения; это не обещание отсутствия служебного хранения
у провайдера. Перед отправкой удалите персональные данные.

Лимит ограничивает число попыток в сутки на один процесс, сбрасывается после
перезапуска и не объединяется между экземплярами. Для публичного сервиса настройте
ограничения расходов у провайдера; при масштабировании замените счётчик общим хранилищем.
API оплачивается отдельно от подписки ChatGPT. Реальную проверку ИИ можно выполнить
только после настройки ключа с доступом к выбранной модели.
