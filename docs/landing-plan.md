# План лендинга «Щит от мошенников» (утверждён к работе, ждёт команды «делай»)

Сохранено 2026-11-03. Делать по скиллам `website-design:landing-page` + VectorLab UX, стиль из `DESIGN.md`.

## Где
Отдельная страница `/about` (FastAPI-маршрут + `about.html`), само приложение на `/` не трогать.
Ссылка «Открыть проверку» ведёт на `/`. На эту страницу будет ссылаться статья на Хабре.

## Секции
1. **Первый экран:** «Проверьте подозрительное сообщение за секунду». Подзаголовок про риск 0–100 и подсказки, что делать. Кнопка «Проверить сообщение». Визуал: настоящий скриншот результата «риск 100».
2. **Примеры** (реальные баллы из `analyzer.py`, проверено 2026-11-01):
   - «Мама, это я, новый номер. Срочно переведи 5000…» → 98, критический
   - «Служба безопасности Сбербанка… безопасный счёт» → 100, критический
   - «Посылка задержана, оплатите 149 руб: cdek-dostavka.xyz» → 70, высокий
   - «Встречаемся завтра в 7 у метро» → 0, низкий
3. **Как это работает:** вставили текст → признаки подсвечены → понятный совет.
4. **Приватность:** текст не сохраняется и не логируется; ИИ-разбор только с согласия.
5. **Бот в VK:** vk.ru/shchit_ot_moshennikov — проверка прямо в мессенджере.
6. **Вопросы:** «Это точно?» (нет, эвристика, честно), «Что с моими данными?», «Это бесплатно?», «Первая загрузка долгая» (бесплатный Render).
7. **Повтор кнопки** «Проверить сообщение». Ссылки на GitHub и «Антимошенник».

## Правила
- Не выдумывать отзывы, число пользователей, рейтинги, логотипы. Отзывов сейчас нет — секцию не делать (или помеченное место, если появятся).
- Без слов «революционный», «уникальный», «инновационный».
- Проверить: 375 / 768 / 1440 px, светлая и тёмная тема, только клавиатура, контраст, title/description/og:image.
